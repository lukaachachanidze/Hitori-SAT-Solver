# Hitori-SAT-Solver
Python project for solving Hitori puzzle using SAT solver.
for Course Propositional and Predicate Logic

## about Hitori
Hitori is puzzle played on grid of numbers. The goal is to shade some cells s.t:
1. No number appears twice in any row or column among unshaded cells
2. shaded cells cannot be horizontaly or vertically adjacent
3. All unshaded cells remain connected.
 ## Project goal
 the program will read Hitori puzzle, convert it into SAT problem, use Glucose solver
 and display the result
